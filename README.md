# StudyMate

StudyMate is a modern Android study planner application designed to help students organize their academic activities in one place. The application provides an easy-to-use interface for managing study schedules, homework, notes, tasks, and exam planning. It is designed to improve productivity, organization, and time management for students.

## Features

### Dashboard
- Modern and user-friendly home screen
- Quick access to all major features
- Clean and responsive design

### Timetable Management
- Create and manage weekly study schedules
- Organize subjects and classes
- Edit and update timetable entries

### Homework Manager
- Add homework and assignments
- Track due dates
- Mark homework as completed
- Edit or delete existing entries

### Notes Management
- Create study notes
- Edit and update notes
- Organize important information
- Quick access to saved notes

### To-Do List
- Manage daily study tasks
- Track completed activities
- Improve productivity and planning

### Exam Planner
- Store exam schedules
- Manage important academic dates
- Keep track of upcoming examinations

### Student Profile
- Save personal information
- Manage student details
- Editable profile section

### Offline Data Storage
- Data is stored locally on the device
- Works without an internet connection
- Information remains available after restarting the application

## Technologies Used

- Kotlin Programming Language
- XML User Interface Design
- Android SDK
- Material Design 3
- Room Database
- SQLite Database
- MVVM Architecture
- Android Jetpack Components
- Repository Pattern
- Gradle Build System

## Architecture

The application follows the MVVM (Model-View-ViewModel) architecture pattern to ensure clean code organization, maintainability, and scalability. Data management is handled using Room Database and Repository components for efficient local storage and retrieval.

## User Experience

StudyMate is built with a focus on simplicity, performance, and usability. The application provides a smooth user experience with modern Material Design components, intuitive navigation, and responsive layouts.
